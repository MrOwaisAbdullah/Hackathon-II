Hackathon 2 — Phase 1 complete.

The task was simple on paper.
Build a todo CLI.

I could've built another solo todo app.
Add tasks. Mark done. Delete.

Most todo apps are built for one person.

But the moment you add "team" to the equation, everything changes.

Real teams assign work. Track owners. Hand off tasks.

So I built a team task CLI instead.

What it does:
👉 Create and assign tasks to team members
👉 Filter by status or assignee
👉 Update and reassign work
👉 Delete when done

Built with Python + Typer.
Published to PyPI today.

```bash
pip install teamflow-console
teamflow
```

The deployment taught me more than the build.
7 different issues. Package structure, imports, .gitignore.
Each one a lesson.

Created a reusable skill from those failures.
So future deployments go smoother.

One thing I keep learning in hackathons:
Standing out isn't about more features.
It's about thinking one step closer to the real world.

Phase 2 will grow this into a team management tool.
The base is ready.
