Here's the complete path:

STEP 1: Install Docker Desktop
Download from the official Docker website
Verify with: docker --version

STEP 2: Install Minikube and Helm
Minikube runs K8s locally on your machine
Helm manages K8s deployments

Download both from their official sites.
Or use package managers like brew or apt.

STEP 3: Start Minikube
minikube start --cpus=4 --memory=8192

This gives you a local K8s cluster with enough resources.

STEP 4: Build Docker images
Create Dockerfile for frontend and backend.
Use multi-stage builds to keep images small.
Build in Minikube's Docker daemon (not Windows Docker).

STEP 5: Deploy with Helm
helm install teamflow ./helm/teamflow --namespace teamflow

That's it.
Your app is now running in Kubernetes.

What I created:

But I hit some walls.

Here are 5 pitfalls that wasted my time:

PITFALL 1: Not enabling standalone output in Next.js
Docker build failed completely.
Fixed by adding output: 'standalone' to next.config.ts

PITFALL 2: Building images in wrong Docker daemon
Built in Windows Docker but Minikube couldn't find them.
Fixed by running: eval $(minikube docker-env) before building

PITFALL 3: Missing .dockerignore
Images were 2GB+ because node_modules got copied.
Fixed by creating .dockerignore file

PITFALL 4: Hardcoding secrets in git
GitHub push protection blocked my commits.
Fixed by using separate values.yaml file (gitignored)

PITFALL 5: Forgetting ingress addon
Could only access via port-forward.
Fixed by running: minikube addons enable ingress
