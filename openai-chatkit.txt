ChatKit JS Frontend with Custom Backend
On the frontend, you configure ChatKit in advanced mode by providing your own API URL and a domain key (client secret). Retrieval Augmentation with Qdrant
In a RAG setup, your ChatKit server can first query Qdrant (or another vector store) to get relevant documents, then feed them as context into the LLM. Qdrant Cloud provides a managed high-performance vector database to store your document embeddings. It is built for “high-dimensional vectors” and large-scale AI applications
qdrant.tech
. Typically, you would use an embeddings model (e.g. from Cohere, HuggingFace, or even OpenAI’s embedding API) to encode your docs, store them in Qdrant, and on each user query retrieve the top-N relevant pieces. Those pieces are then included in the ChatKit agent prompt or as system messages. In this way, the agent has up-to-date knowledge without relying on the LLM’s internal memory. (You could embed with any provider or free model; for example, OpenAI’s text-embedding-3 models are natively supported by Qdrant, but many open-source embeddings also work.)

### Backend Setup (FastAPI + OpenAI ChatKit Python SDK + Qdrant + Non-OpenAI LLM)
1. **Install Dependencies**:
   - Install the OpenAI ChatKit Python package: `pip install openai-chatkit`.
   - Add other libraries: `pip install fastapi uvicorn qdrant-client google-generativeai` (for Gemini; swap with `openrouter` or your preferred LLM client if using OpenRouter).
   - No OpenAI Python SDK or API key is needed here—ChatKit Python can run standalone in custom mode.

2. **Implement a Custom ChatKit Server**:
   - Subclass `chatkit.server.ChatKitServer` and override the `respond` method. This is where you'll handle incoming user messages, perform RAG (retrieve from Qdrant), generate responses with your non-OpenAI LLM, and stream back events/widgets to the frontend.
   - Use a persistent store for threads/messages (e.g., default SQLite via `chatkit.store.Store`).
   - Integrate Qdrant for RAG: On app startup or per-session, embed documents into Qdrant Cloud (using your Qdrant API key/URL). In `respond`, embed the user query, search Qdrant for relevant chunks, and pass them as context to your LLM.

   Example code structure (in `server.py`):

   ```python
   import os
   from chatkit.server import ChatKitServer, Response, stream_text, stream_widget
   from chatkit.store import Store
   from qdrant_client import QdrantClient
   from google.generativeai import GenerativeModel  # Or your LLM client (e.g., OpenRouter)
   from fastapi import FastAPI, Request
   from fastapi.responses import StreamingResponse

   # Qdrant setup (use your Qdrant Cloud URL and API key)
   qdrant_client = QdrantClient(url="https://your-qdrant-cloud-url", api_key="your-qdrant-api-key")
   collection_name = "your_rag_collection"  # Assume pre-created with embeddings

   # LLM setup (example: Gemini; replace with OpenRouter or other)
   gemini_model = GenerativeModel("gemini-1.5-pro")  # Use your Google API key via env var GOOGLE_API_KEY

   class CustomChatKitServer(ChatKitServer):
       def __init__(self, store: Store):
           super().__init__(store)

       async def respond(self, message_id: str) -> Response:
           # Get the user message from the store
           message = await self.store.get_message(message_id)
           user_query = message['content']

           # RAG: Embed query and search Qdrant (use your embedding model, e.g., Sentence Transformers)
           from sentence_transformers import SentenceTransformer
           embedder = SentenceTransformer('all-MiniLM-L6-v2')
           query_embedding = embedder.encode(user_query).tolist()
           search_results = qdrant_client.search(
               collection_name=collection_name,
               query_vector=query_embedding,
               limit=5
           )
           context = "\n".join([hit.payload['text'] for hit in search_results])  # Extract relevant chunks

           # Generate response with non-OpenAI LLM (Gemini example)
           prompt = f"Context: {context}\n\nUser: {user_query}\nAssistant:"
           llm_response = gemini_model.generate_content(prompt).text

           # Stream the response back (supports text, widgets, etc.)
           async def stream_generator():
               yield from stream_text(llm_response)
               # Optional: Yield custom widgets, e.g., yield from stream_widget({"type": "card", "content": "Some UI element"})

           return StreamingResponse(stream_generator(), media_type="application/x-ndjson")

   # FastAPI app to expose the ChatKit endpoint
   app = FastAPI()
   store = Store(db_path="chatkit.db")  # Persistent SQLite store
   server = CustomChatKitServer(store)

   @app.post("/chatkit/respond")
   async def handle_respond(request: Request):
       # Forward to your custom server (handle auth if needed, e.g., via headers)
       body = await request.json()
       message_id = body.get("message_id")
       return await server.respond(message_id)

   # Additional endpoints for session creation, file uploads, etc. (implement as needed)
   @app.post("/chatkit/sessions")
   async def create_session():
       # Custom session logic (no OpenAI key needed)
       session_id = "your-generated-session-id"
       return {"session_id": session_id, "client_token": "your-jwt-or-token"}

   if __name__ == "__main__":
       import uvicorn
       uvicorn.run(app, host="0.0.0.0", port=8000)
   ```

   - Run with `python server.py`.
   - Customize authentication (e.g., JWT) in session creation—no OpenAI key required.
   - For tools/actions (e.g., if your chatbot needs to invoke external APIs), use ChatKit's `ActionConfig` and register them in the server.
   - Handle file uploads/previews with a custom `FileStore`.

3. **RAG-Specific Integration**:
   - Pre-load documents: Use Qdrant client's `upsert` to embed and store chunks (e.g., via a setup script).
   - In `respond`, augment the LLM prompt with retrieved context to enable RAG.
   - For embeddings, use a non-OpenAI model like Hugging Face's Sentence Transformers (compatible with Qdrant).
